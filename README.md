# ToolNestz 🪹

> **ToolNestz** is a modern, responsive, and privacy-first everyday tools hub. Features **35+ fully implemented client-side tools** across Calculators, Converters, Date & Time, Text, Generators, Developer Utilities, and Everyday Tools.

## ✨ Features

- 🧮 **35+ All-in-One Client-Side Tools**: 100% browser-processed computations with zero external tracking or data collection.
- 🎨 **Cute & Minimal Aesthetic**: Friendly owl mascot (**Nestie**), soft rounded cards, pastel tint highlights, and legible rounded typography.
- 🌙 **Dark & Light Mode**: Full theme switching with automatic system theme detection and local storage persistence.
- 🔍 **Instant Search (`Ctrl + K` / `/`)**: Global modal search bar accessible anywhere via keyboard shortcut or header trigger.
- ⭐ **Favorites & History**: Star frequently used tools to pin them to the top dashboard and track recently visited tools.
- 📱 **Fully Responsive**: Optimized for smartphones, tablets, and desktop displays.

## 🧰 Tools Breakdown

### 🧮 Calculators (7 Tools)
- **Scientific Calculator**: Trigonometry ($\sin, \cos, \tan$), logarithms, powers, factorials, memory functions ($MC, MR, M+, M-$), calculation history, and physical keyboard support.
- **Percentage Calculator**: 4-in-1 tool for percentage of a number, ratio percentage, % increase/decrease.
- **BMI & Health Calculator**: Metric & Imperial support, visual color-coded BMI gauge pointer, health risk categories, and daily BMR calorie estimate.
- **Tip & Gratuity Calculator**: Tip presets ($10\%, 15\%, 18\%, 20\%, 25\%$), bill split per person, and round-up helper.
- **Quick Bill Splitter**: Itemized group expense splitter with tax/tip allocation and copyable text summary.
- **Mortgage & Loan EMI Calculator**: Monthly EMI payments, total interest payable, and principal vs. interest breakdown bar.
- **Compound Interest Growth**: Initial deposit, monthly contribution, compounding frequency, and future savings balance projection.

### 🔄 Converters (4 Tools)
- **Universal Unit Converter**: Length, Weight/Mass, Volume, Temperature, Area, and Digital Storage units.
- **Instant Currency Converter**: 30+ major world currencies with offline baseline conversion and live rate refresh.
- **Color Studio & Converter**: Converts HEX, RGB, HSL, CMYK formats with a 5-shade monochrome palette generator and 1-click copy.
- **Speed & Pace Converter**: km/h, mph, m/s, knots, running pace (min/km, min/mile), and 5k/10k/half/full marathon race time estimates.

### ⏰ Date & Time (6 Tools)
- **Cute Exact Age Calculator**: Exact age in years, months, days, total days/hours/minutes lived, day born, next birthday countdown, and celebratory confetti!
- **World Timezone Converter**: Compare local times across major world cities with reference datetime picker.
- **Date Difference & Add/Subtract**: Total days and business days between dates, or add/subtract days/weeks/months from any date.
- **Event Countdown & Alarm**: Visual progress circular countdown timer with quick presets and audio chime alert toggle.
- **Precision Stopwatch & Laps**: Millisecond accuracy, lap time recorder, lap difference visualizer, and CSV lap exporter.
- **Pomodoro Focus Companion**: 25m Focus / 5m Short Break / 15m Long Break intervals with task tracker and session counter.

### 📝 Text & Productivity (5 Tools)
- **Text Case Converter**: 10 preset text case transformations (UPPERCASE, lowercase, Title Case, Sentence case, camelCase, PascalCase, snake_case, kebab-case, CONSTANT_CASE, alternating).
- **Word & Character Counter**: Words, characters (with/without spaces), sentences, paragraphs, reading time, speaking time, and top frequent keywords.
- **Lorem Ipsum & Cute Dummy Text**: Classic Lorem Ipsum, ✨ Emoji Ipsum, 🍔 Foodie Ipsum, and 🐱 Cat Ipsum!
- **Markdown Live Editor**: Side-by-side Markdown editor and rendered HTML previewer with copy HTML and markdown options.
- **Text Diff Checker**: Line-by-line comparison highlighting additions (green) and deletions (red).

### 🎲 Generators (5 Tools)
- **Cute QR Code Generator**: URL/Text to QR code, custom foreground/background colors, and PNG image download.
- **Strong Password Generator**: Custom character length, uppercase/numbers/symbols toggles, memorable passphrase mode, and security strength meter.
- **Random Number & Decision Picker**: Range number generator, item list picker wheel, coin flip, and multi-sided dice roller ($D4, D6, D8, D10, D12, D20$).
- **UUID / GUID Generator**: Batch v4 UUID generator with uppercase and hyphens controls.
- **Cryptographic Hash Generator**: SHA-256, SHA-512, and SHA-1 hashes generated via Web Crypto API.

### 💻 Developer Tech Utilities (4 Tools)
- **JSON Formatter & Validator**: Beautify with 2/4 space indentation, minifier, syntax error validator with line pointers.
- **URL Encoder & Decoder**: Safe URI component encoding and decoding.
- **Base64 Encoder & Decoder**: Text to Base64, Base64 to text, and image file to Data URI string.
- **Regex Matcher & Tester**: Real-time regular expression tester with flags ($g, i, m$), match count, and group extraction details.

### 🛠️ Everyday Utilities (4 Tools)
- **Aspect Ratio Calculator**: Presets ($16:9, 4:3, 1:1, 9:16, 21:9$), dimension solver, and visual box preview frame.
- **Discount & Sales Savings**: Original price, store discount %, extra coupon %, sales tax %, net final price, and total savings.
- **Fuel Cost & Trip Splitter**: Trip distance, fuel efficiency ($L/100km$), gas price, total fuel needed, total cost, and per-passenger share.
- **Daily Hydration & Water Tracker**: Target water intake calculator based on weight & exercise, with interactive cup logging.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm

### Installation & Local Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/CoderSugata/ToolNestz.git
   cd ToolNestz
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```
